**Dapur Kilat — Sizzle Stall**: an original street-kitchen cooking game for desktop Chrome. Orders land on the board with patience timers; take ingredients from the counter, grill the patty, egg and chicken (don't let them burn), chop the lettuce and tomato, stack each dish across two assembly plates, and serve before the bar empties to build your combo. Pure vanilla Canvas 2D — no libraries, no network, no build step.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
# hand-in check: mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
